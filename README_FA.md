# Seven of Spades — اسلایدشو تلگرام

## نکته مهم
این پروژه یک صفحه وب اسلایدشو می‌سازد؛ پست بومی کانال تلگرام با کاروسل اینستاگرامی ایجاد نمی‌کند. ربات لینک صفحه را می‌دهد تا آن را در کانال منتشر کنید.

## راه‌اندازی
1. این فایل‌ها را در یک مخزن GitHub آپلود کنید.
2. در Render گزینه New + > Blueprint را بزنید و مخزن را وصل کنید.
3. در Environment مقدار `BOT_TOKEN` را با توکن BotFather و مقدار `BASE_URL` را با آدرس سرویس Render (مثل `https://your-service.onrender.com`) تنظیم کنید.
4. Deploy کنید.
5. در تلگرام به ربات `/start` بفرستید، عکس‌ها را ارسال کنید و `/done` را بزنید.
6. لینک پیش‌نمایش را باز کنید و از گزینه اشتراک‌گذاری، کانالتان را انتخاب کنید.

## محدودیت نسخه آزمایشی
- نسخه رایگان Render ممکن است پس از بی‌کاری بخوابد.
- پایگاه داده در مسیر موقت قرار دارد؛ با راه‌اندازی مجدد ممکن است آلبوم‌ها پاک شوند. برای استفاده پایدار باید فضای ذخیره‌سازی دائمی/پایگاه داده متصل شود.
- هر کسی که لینک اسلایدشو را داشته باشد می‌تواند آن را ببیند.
- توکن را فقط در Environment Variables سایت Render وارد کنید؛ هرگز در GitHub یا چت منتشر نکنید.
